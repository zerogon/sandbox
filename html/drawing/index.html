🏝️ 휴양지 랜덤 추첨

① 객실 LIST(정원) 업로드 → ② 신청명단 업로드 → ③ 매칭 검수 → ④ 추첨 → ⑤ 결과/다운로드

1

객실 LIST 업로드 — source.xlsx (객실별 추첨 정원)

2

신청명단 업로드 — target.xlsx (첫 시트만 사용)

3

매칭 검수 — 객실(정원) ↔ 신청 그룹 연결

자동 정규화 자동 매칭 추천 유사 후보 — 확인 권장 미매칭 직접 연결 필요 신청없음 신청자 0 (빈 객실)
4

추첨 실행 — 호반 → 롯데 → 대명 → 오크밸리 → 한화 / 1인 최대 1객실 / 완전 무작위

버튼을 누를 때마다 새로 무작위 추첨합니다(매 실행 결과 상이).
5

결과 / 리포트 — 다운로드
