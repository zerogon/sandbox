엑셀 유틸리티

엑셀 업로드 → 자동 처리 → 결과 다운로드

엑셀 파일을 업로드하면 3개 조합이 같은 행에서 첫 행만 남기고 나머지를 제거합니다.
결과 파일은 2개 시트로 저장됩니다 — 원본(업로드 그대로) / 중복제거(정렬 + 중복 제거 최종본, 탭 노란색).
헤더는 A1 셀부터 시작해야 하며, 반드시 컬럼이 있어야 합니다.

1. 샘플 데이터

테스트용 샘플: 다자녀(중복 아님)와 진짜 중복이 섞인 시나리오.

2. 엑셀 업로드 및 중복 검사

선택된 파일 없음

신청 명단 엑셀을 업로드하면 자동으로 추첨해 결과 파일을 다운로드합니다.
